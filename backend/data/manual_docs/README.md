# 手動補充文件

「全國法規資料庫」官方 API（`/api/Ch/Law/JSON`、`/api/Ch/Order/JSON`）只收錄正式「法律」與「命令」，
不包含內政部公告的定型化契約應記載及不得記載事項（例如「預售屋買賣定型化契約應記載及不得記載事項」、
「成屋買賣定型化契約應記載及不得記載事項」）。這類文件對驗屋糾紛非常重要。

## 方法一（建議）：執行抓取腳本

`glrs.moi.gov.tw`（內政部主管法規共用系統）會擋掉雲端沙盒常見的爬蟲 UA，因此抓取腳本必須在
**你自己的電腦或伺服器**（一般家用/公司網路即可）執行：

```bash
cd backend
python -m app.fetch_manual_docs
```

執行完會自動產生這個資料夾裡的 JSON 檔，並提示是否需要人工檢查分條結果。
完成後務必打開檔案核對內容是否為最新版本，再執行 `python -m app.build_index` 重建索引。

## 方法二：手動貼上全文

1. 到內政部地政司公告頁面，複製官方公告的最新全文（務必確認是最新版本、注意「應記載」與「不得記載」分開列出）。
2. 在這個資料夾新增一個 `*.json` 檔，格式如下：

```json
{
  "name": "預售屋買賣定型化契約應記載及不得記載事項",
  "last_update": "2024-01-01",
  "source_url": "https://（貼上官方公告網址）",
  "articles": [
    { "no": "應記載事項一", "content": "（貼上官方原文）" },
    { "no": "不得記載事項一", "content": "（貼上官方原文）" }
  ]
}
```

3. 執行 `python -m app.build_index` 重建索引即可生效。
